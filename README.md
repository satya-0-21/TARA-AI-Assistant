# T.A.R.A - Bilingual Desktop AI Assistant 🤖

T.A.R.A is a local, Python-based desktop AI assistant designed for seamless bilingual voice recognition in **Telugu** and **English**. Inspired by sci-fi AI interfaces, it features a Marvel-style Heads-Up Display (HUD) for visual feedback.

## Ecosystem Gap
Current AI assistants heavily favor English and cloud-dependent processing. T.A.R.A fills the gap by providing local, offline-capable automation with native support for regional Indian languages (Telugu), making desktop automation accessible to a wider, non-native English speaking demographic.

## Features (In Development)
* 🎙️ **Bilingual Speech Recognition** (Telugu `te-IN` & English `en-IN`)
* 🖥️ **Custom UI/HUD** using Python visual libraries
* ⚙️ **Local Desktop Automation** (App launching, file management)
* 🔒 **Privacy First** (Local processing where possible)

## Getting Started
Clone the repository and install the dependencies to test the alpha voice-engine.
